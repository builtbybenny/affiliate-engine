# Stack & Save — Complete Setup Guide

This guide takes you from zero to a fully automated posting machine.
Do the stages **in order**. Do not skip ahead.
Every field you will see on any screen is written out here. Nothing is left to guess.

**Total time:** about 2 hours, once. **Cost:** zero.
**When you finish:** pages post twice a day by themselves, with your laptop off.

Your three identities, used everywhere in this guide:

| Thing | Value |
|---|---|
| Brand name | Stack & Save |
| Handle (IG and FB) | stackandsavehq |
| Niche | SaaS tools / free trials |

Keep this PDF open while you work. Tick stages off as you finish them.

# STAGE 1 — Instagram account (15 minutes)

You will create a professional Instagram account for the brand.

1.1. Open instagram.com in your browser and log in to your personal Instagram
(or create one if you have none — you will not use this account publicly).

1.2. Click your profile picture (top right) and choose "Switch to professional
account". If you do not see it, go to Settings and look for
"Account type and tools".

1.3. Instagram shows a setup wizard. Enter these values:

| Screen question | What to pick / type |
|---|---|
| What best describes you? | Creator (or Business — either works; pick Creator) |
| Select a category | Digital creator (alternatives if Digital creator is missing: "Content creator", "Entrepreneur") |
| Do you want to display it? | Your choice; both fine. Recommend Yes for credibility |
| Are you a musician? | No |
| Contact options | Skip (press Next / Skip) |
| Share logins using Accounts Center | Skip |
| Connect to Facebook now? | SKIP for now — Stage 2 does it properly |

1.4. Set your profile fields. Go to "Edit profile" and fill exactly:

| Field | Value to paste |
|---|---|
| Name (NOT username) | Stack & Save \| SaaS Tools  (max 30 chars — longer gets rejected) |
| Username | stackandsavehq |
| If taken, try in order | stackandsave, stackandsave_, get.stackandsave |
| Website | (leave empty now — you will paste in Stage 6.4) |
| Bio | The stack that saves you hours. Free trials only. [press Enter once here] New SaaS tools weekly. Honest takes. Start free ↓ |
| Category (public) | Digital creator |
| Profile photo | Upload file: public/brand/avatar.png (from your project folder) |

1.5. Confirm the account is a professional account:
Settings -> Account type and tools -> it should say "Switch to personal
account" (meaning you already are professional).

Stage 1 done when: your profile shows "Digital creator" under the name,
avatar uploaded, bio pasted.

# STAGE 4 — Meta developer app + permissions (20 minutes)

This creates the "key" the automation uses. Free, official, safe.

4.1. Go to developers.facebook.com and log in with your Facebook account.

4.2. Click "Get Started" (or My Apps -> Create App).

4.3. Fill the app creation form exactly:

| Field | Value to paste |
|---|---|
| App name | Stack & Save Engine |
| App contact email | your real email |
| App purpose | Manage business integration (or "Business" if asked as type) |
| If asked "What do you want to build?" | Business |

4.4. Inside the app dashboard, left menu -> "Use cases" or "Products" ->
find "Instagram Graph API" and add it. Also add "Facebook Login for Business"
if shown.

4.5. Left menu -> Settings -> Basic. Fill:

| Field | Value |
|---|---|
| App domains | meta-fb-redirects.com (Meta no longer accepts "localhost"; any placeholder domain works — the engine never uses it) |
| Contact email | your email |
| Privacy Policy URL | skip for now (not needed while app is in Development mode) |
| Category | Business and pages |
| Icon | skip |
| Save changes (button bottom) | click it |

4.6. Note two values shown on that Basic page: App ID and App secret.
You WILL need both in Stage 5 — the wizard uses them to make your posting
token never expire.

4.7. Add yourself as a tester/owner (usually automatic — you are the admin
because you created the app).

4.8. Leave the app in Development mode (toggle at top of dashboard says
"Development"). This is enough for posting to your own accounts. If a screen
ever says the app must be live, only then continue to 4.9.

4.9. (Only if required) App Review: click "Start verification", provide the
screencast it asks for showing your posting dashboard; the permissions used
by this engine (instagram_content_publish, instagram_basic,
pages_read_engagement, pages_show_list, pages_manage_posts,
instagram_manage_comments, business_management) are standard for
"manage my own business" cases.

Stage 4 done when: the app exists, Development mode shows on the dashboard.

# STAGE 6 — GitHub: free hosting + 24/7 scheduler (15 minutes)

6.1. Go to github.com and create a free account (or log in).

6.2. Click the + icon (top right) -> "New repository".

**Owner dropdown: pick your PERSONAL account** (or a dedicated org), not an
org hosting your existing site/repos — keeps this experiment isolated.

| Field | Value |
|---|---|
| Owner | your personal account (or a new org) |
| Repository name | affiliate-engine |
| Description (optional) | Automated SaaS affiliate posting |
| Visibility | Private (recommended) |
| Add README | Do NOT tick |
| Click "Create repository" | |

6.2b. GitHub Pages on a PRIVATE repo requires GitHub Pro/Team. On Free:
  - Option A (zero cost): make THIS repo public — your site is just tool
    links and renders; nothing sensitive. Secrets stay private regardless.
  - Option B: your existing hosted website — put a folder /stack on it and
    serve docs/ contents there instead (set PUBLIC_MEDIA_BASE_URL to it).
  - Option C: GitHub Pro (~$4/mo) if you insist on private + Pages.

6.3. Connect your local project to it. In your project terminal run (replace YOURUSER):

    git init
    git add .
    git commit -m "affiliate engine initial"
    git branch -M main
    git remote add origin https://github.com/YOURUSER/affiliate-engine.git
    git push -u origin main

(If git is missing: install from git-scm.com, accept defaults, reopen terminal.)

6.4. Turn on Pages (this is your free link-in-bio hosting):
Repo -> Settings -> left "Pages" -> "Deploy from a branch" ->
Branch: main, Folder: /docs -> Save.
The site URL appears in ~2 minutes, like https://YOURUSER.github.io/affiliate-engine/

6.5. Paste that URL as your bio Website field:
   - Instagram: Edit profile -> Website -> paste -> Done
   - Facebook Page: Page -> Edit details -> Website -> paste

6.6. Add the scheduler secrets: Repo -> Settings -> "Secrets and variables" ->
"Actions" -> button "New repository secret" — add each of these five,
one at a time, values copied from your .env file:

| Secret Name field | Value field |
|---|---|
| IG_USER_ID | (value of IG_USER_ID from .env) |
| FB_PAGE_ID | (value of FB_PAGE_ID from .env) |
| ACCESS_TOKEN | (value of ACCESS_TOKEN from .env) |
| GEMINI_API_KEY | (AI copywriter — copy the value from your .env) |
| PEXELS_API_KEY | (stock photos — copy the value from your .env) |

6.7. About the .env file: it holds your secrets. It is already listed in
.gitignore, so git will never upload it — that is correct and safe. You never
commit it, and you never add it to GitHub. The scheduler workflow gets its
Pages URL automatically. Nothing to do in this step.

6.8. Test the scheduler once by hand: Repo -> Actions tab -> left "scheduler" ->
"Run workflow" dropdown -> green "Run workflow" button -> wait ~5 minutes.
Watch the steps go green. Then check instagram.com/@stackandsavehq — first post
should be live.

Stage 6 done when: the manual workflow run posts to your IG + FB.

# Troubleshooting quick answers

| Symptom | Fix |
|---|---|
| "Insufficient Developer Role" in explorer | Log into the right FB account; you must be admin of both app and Page |
| Token wizard finds no Pages | Stage 3 link missing, or pages_show_list permission missing — redo 4.4/5.4 |
| Publish error "media download failed" | Pages not live yet; wait 2 min after workflow or check Settings->Pages |
| Publish error 9007 / PERMISSION | Page Publishing Authorization required: Page settings -> New Pages Experience -> complete the 2-step check |
| Reels publish but no sound | No music file in assets/music/ — drop any royalty-free .mp3 there |
| Workflow red at "Publish" step | Run doctor.py --live; token likely invalidated by password change — rerun setup_tokens.py |
